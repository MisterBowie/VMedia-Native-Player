# VMedia Native Player — 产品需求文档 (PRD)

> 本文档定义产品功能需求、UI/UX 规范和优先级排序。

## 1. 产品定位

一款面向 Linux 桌面用户的**本地视频播放器**，追求 IINA 级别的简洁体验：

- 窗口干净，视频内容始终是主角
- 控件克制，操作反馈轻
- 快捷键顺手
- 不让播放器看起来像网页应用

## 2. 功能需求

### 2.1 播放核心

| 功能 | 描述 | 优先级 |
|---|---|---|
| 打开本地文件 | 文件对话框 / 命令行 / 拖入 | ★★★★★ |
| 播放/暂停 | 空格键 + 按钮 | ★★★★★ |
| 进度跳转 | 拖动进度条 + 快捷键 ±5s/±30s | ★★★★★ |
| 音量控制 | 滑块 + 快捷键 + 静音 | ★★★★★ |
| 全屏 | F/F11 切换 + 双击视频 | ★★★★★ |
| 播放速度 | 0.25x ~ 3.0x 选择器 | ★★★★ |
| 字幕轨切换 | 内嵌字幕列表切换 | ★★★ |
| 音轨切换 | 多音轨选择 | ★★★ |
| 外挂字幕 | 加载 .srt/.ass 文件 | ★★★ |
| 字幕延迟 | ±0.1s 调整 | ★★ |
| 音频延迟 | ±0.1s 调整 | ★★ |
| 截图 | 保存当前帧到文件 | ★★ |
| A-B 循环 | 设定循环区间 | ★★ |

### 2.2 控制面板

|---|---|---|
| 悬浮毛玻璃面板 | 半透明背景、圆角 | ★★★★★ |
| 自动隐藏 | 鼠标停止 1.5s 后隐藏 | ★★★★★ |
| 鼠标移动显示 | 鼠标移动/进入窗口即显示 | ★★★★★ |
| 可拖动 | 控制栏可拖到任意位置 | ★★★★ |
| 响应式宽度 | 60% 窗口宽度，最大 600px | ★★★★ |
| 圆形播放按钮 | 极简设计 | ★★★ |

### 2.4 播放列表

| 功能 | 描述 | 优先级 |
|---|---|---|
| 自动填充 | 扫描同目录媒体文件 | ★★★★ |
| 右侧滑出面板 | 半透明、全高 | ★★★★ |
| 高亮当前文件 | 正在播放的文件高亮 | ★★★ |

| 功能 | 描述 | 优先级 |

## 3. UI/UX 规范

### 3.1 视图结构

| 视图 | 说明 | 阶段 |
|---|---|---|
| `NowPlayingView` | 全屏沉浸播放，叠加控制条 | 阶段 1 ✅ |
| `LibraryView` | 海报墙网格 | 阶段 3 |
| `SettingsView` | 媒体库目录、播放设置 | 阶段 3 |

### 3.2 控制条布局

```
┌──────────────────────────────────────────────────────────┐
│  0:00 ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  -0:00 │
│  📂     ⏮  ▶  ⏭      🔊  1.0x  ≡  ⛶                    │
└──────────────────────────────────────────────────────────┘
```

| 区域 | 内容 |
|---|---|
| 顶行 | 进度条 + 左侧当前时间 + 右侧剩余时间 |
| 左侧 | 打开文件按钮 |
| 中央 | 上一曲 · 播放/暂停 · 下一曲 |
| 右侧 | 音量 · 倍速 · 播放列表 · 全屏 |

### 3.3 视频区域交互

| 操作 | 行为 |
|---|---|
| 双击 | 全屏/退出全屏 |
| 单击 | 暂停/继续 |
| 滚轮 | 调音量 |

### 3.4 右键上下文菜单

```
暂停/继续
倍速播放 ▸  (0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x)
──────────
字幕轨 ▸
音轨 ▸
字幕延迟
──────────
截图
A-B 循环
──────────
媒体信息
文件属性
```

### 3.5 OSD 提示

快捷键操作后的屏幕反馈：
- "音量 75%"、"快进 10s"、"1.5x 倍速"
- 居中偏上显示，1.5 秒后淡出

### 3.6 快捷键

| 键 | 操作 |
|---|---|
| `Space` | 暂停/继续 |
| `←` / `→` | 快退/快进 5 秒 |
| `Shift+←` / `Shift+→` | 快退/快进 30 秒 |
| `↑` / `↓` | 音量 ±5% |
| `M` | 静音切换 |
| `F` / `F11` | 全屏切换 |
| `O` | 打开文件 |
| `L` | 播放列表 |
| `Esc` | 退出全屏 |
| `[` / `]` | 减速/加速 0.1x |
| `S` | 截图 |
| `J` / `K` | 字幕延迟 ±0.1s |
| `I` | 媒体信息面板 |

## 4. 不做的事

- 多用户 / 账号系统
- 云同步 / 远程串流
- 复杂推荐系统
- 平台化扩张（iOS / Android / Web）
