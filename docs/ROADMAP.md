## 阶段 1：最小播放器 🟢 基本完成

> 目标：能稳定播放视频，具备基础交互体验。

| 功能 | 状态 | 备注 |
|---|---|---|
| GTK4 + Libadwaita 窗口 | ✅ | 暗色主题，1280×800 默认尺寸 |
| libmpv 集成 | ✅ | OpenGL render API，硬件加速 |
| 打开本地文件（对话框） | ✅ | 文件夹图标按钮 |
| 命令行打开文件 | ✅ | `cargo run -- /path/to/file.mp4` |
| 播放 / 暂停 | ✅ | 空格键 + 按钮 |
| 相对 Seek（±5s / ±30s） | ✅ | 方向键 + Shift |
| 绝对 Seek（进度条拖拽） | ✅ | 自定义 SeekBar 组件 |
| 音量控制 | ✅ | 竖向弹出滑块，5 级图标 |
| 静音切换 | ✅ | M 键 + 图标点击 |
| 全屏 | ✅ | F / F11 / 双击视频 |
| 播放速度控制 | ✅ | 0.25x ~ 3.0x 选择器 |
| 基础快捷键 | ✅ | Space, ←→, ↑↓, M, F, O |
| 控制条自动隐藏 | ✅ | 1.5 秒无操作隐藏，Capture 阶段事件 |
| 控制条可拖动 | ✅ | 基于 Overlay 坐标的 GestureDrag |
| 控制条响应式宽度 | ✅ | 60% 窗口宽度，max 600px |
| 悬浮毛玻璃控制面板 | ✅ | rgba 背景 + 圆角 + 白色进度条 |
| 视频区域鼠标交互 | ✅ | 单击暂停，双击全屏 |
| 时间显示 | ✅ | 当前时间 / 剩余时间 |
| 播放列表面板 | ✅ | 右侧滑出，自动扫描同目录文件 |
| 播放恢复 | ✅ | 记住上次文件 + 位置，暂停恢复 |
| 右键上下文菜单 | ✅ | 基础菜单已实现 |

## 版本历史

### v0.1.0（2026-05-09）

**首个公开版本**

- 基于 libmpv + GTK4 + Libadwaita 的原生视频播放器
- 悬浮毛玻璃控制面板（自动隐藏、可拖动、响应式宽度）
- 白色极简进度条 + 圆形播放按钮
- 播放速度控制（0.25x ~ 3.0x）
- 音量控制（5 级图标 + 竖向弹出滑块）
- 右侧滑出播放列表面板
- 智能播放恢复（记住上次文件和位置，暂停状态恢复）
- 完整快捷键支持
- 右键上下文菜单

## 不纳入路线图的方向

- ❌ 多用户 / 账号系统
- ❌ 云同步 / 远程串流
- ❌ 复杂推荐系统
- ❌ 平台化扩张（iOS / Android / Web）

> 优先让它成为一个真正顺手、稳定、长期可维护的播放器，
> 而不是一个看起来很大但播放器本身不够扎实的平台。
